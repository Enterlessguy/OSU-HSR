# Checkpoint logs

Every project checkpoint gets a numbered log in this folder (e.g.
`checkpoint-1.md`). Each log records what was included, the state at the time
of the checkpoint, and pointers to the next open items.

- `checkpoint-1.md` - HSR checkpoint 1 (initial project import).
- `checkpoint-2.md` - HSR checkpoint 2 (version 1.5 jerk/continuity tuning).
